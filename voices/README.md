# Références vocales personnelles

`reddington_reference.wav` contient la référence fournie pour Red. Le profil
`reddington` de Chatterbox est actif dans `config.yaml`.

Le WAV original reste dans Téléchargements ; la copie du projet est inchangée.
Les WAV de ce dossier sont privés et ignorés par Git. Les profils se règlent
dans `voices`, puis se sélectionnent avec `tts.profil`.

Voir [le guide Chatterbox](../docs/chatterbox.md) pour l'installation et le test.
